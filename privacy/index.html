Memdo 개인정보 처리방침

시행일 2026-08-25 · 최종 수정일 2026-08-25 · 버전 1.0

Summary (English) — Memdo is a personal schedule app. We store what you enter (schedule items, optional workout logs) and your sign-in identity from Apple/Google/GitHub. Optional AI features either run entirely on your device, or — if you connect your own OpenRouter API key — send only what's needed for that request to OpenRouter under your own account, never sold or used to train models we control. You can request full account and data deletion at any time. Contact: GitHub Issues.

이 문서는 Memdo(이하 "서비스")가 어떤 정보를 어떤 목적으로 처리하는지 설명합니다. 서비스의 핵심 일정 관리 기능은 별도 동의 없이 사용할 수 있으며, 알림·캘린더 연동·AI·뉴스 브리핑처럼 선택적인 기능만 각각 별도의 동의를 거쳐 활성화됩니다.

2. AI 기능과 데이터 흐름

AI 기능은 기본적으로 꺼져 있으며, 사용자가 명시적으로 켜야 동작합니다. 두 가지 실행 경로가 있습니다.

  • 온디바이스: 지원 기기에서는 Apple의 기기 내 모델(FoundationModels)이 사용되며, 요청 내용이 기기 밖으로 전송되지 않습니다.
  • 클라우드(BYOK): 온디바이스를 지원하지 않는 기기이거나 사용자가 더 큰 모델을 원할 경우, 사용자 본인이 연결한 OpenRouter API 키로 요청을 처리합니다. 이때 필요한 최소한의 내용만 OpenRouter로 전송되며, Memdo는 이 통신 내용을 자체 목적으로 저장·학습에 사용하지 않습니다.

AI가 일정을 생성·수정·삭제하기 전에는 항상 사용자의 명시적 승인이 필요합니다. AI 실행 기록에는 호출된 기능 이름, 실행 시각, 처리 결과 같은 최소 메타데이터만 남기며, 일정 제목이나 메모 원문은 실행 기록에 별도로 저장하지 않습니다.

4. 제3자 서비스

서비스 제공을 위해 아래 외부 서비스를 이용하며, 각 서비스는 자체 개인정보 처리방침을 따릅니다.

  • Apple, Google, GitHub — 로그인(OAuth), 사용자가 직접 개시
  • Supabase — 계정·일정 데이터 저장 및 인증 인프라
  • OpenRouter — 클라우드 AI 기능 사용 시, 사용자 본인의 API 키로 호출
  • Google Calendar API — 사용자가 연동한 경우에만, 읽기 전용
  • Slack — 사용자가 직접 발급한 Webhook 주소로만 전송

5. 계정 및 데이터 삭제

사용자는 언제든 계정과 그에 연결된 데이터 전체의 삭제를 요청할 수 있습니다. 설정 화면에서 직접 요청하는 기능을 준비 중이며, 그 전까지는 아래 문의 채널로 삭제를 요청하면 계정과 데이터를 삭제합니다. Apple로 로그인한 계정의 경우, 가능한 범위에서 Apple 로그인 인증도 함께 해제합니다. 이 절차가 변경되면 이 문서의 최종 수정일을 갱신합니다.

6. 아동 대상 여부

서비스는 만 14세 이상 사용자를 대상으로 하며, 만 14세 미만을 의도적으로 대상으로 하지 않습니다.
