## 1. 내비게이션

하단 탭은 세 개만 사용한다.

```text
오늘 | 캘린더 | 설정
```

- 오늘: 계획, 일정, 하루 요약, 뉴스
- 캘린더: 월간 날짜와 하루의 분위기
- 설정: 관심사, 알림, 개인정보, 외부 연결

검색은 캘린더 헤더에서 펼치는 도구이며 별도 탭을 사용하지 않는다. Agent는 세 탭의 시스템 탭바 위에 항상 접근 가능한 Dock으로 둔다. 오늘 요약은 알림이나 오늘 화면에서 여는 상세 시트다. 페이지별 최신 위계와 상태는 [페이지별 UI/UX 계약](./27-page-ui-ux-contract.md)을 따른다.

## 2. 온보딩

### 화면 1 — 제품 소개

필드:

- 제품 한 문장
- 시작 버튼

### 화면 2 — 나의 하루 스타일

필드:

- 기본 분위기: 집중·여유·활기·회복·설렘
- 기본 테마
- 건너뛰기

### 화면 3 — 하루 요약 시간

문구:

> 하루를 정리하고 싶은 시간을 알려주세요. 완료되지 않은 일정이 있으면 그때 가볍게 확인할게요.

필드:

- 활성화 토글
- 시간 선택
- 요일: 매일 또는 선택 요일
- 조용한 시간과 충돌 경고

기본값은 사용자가 직접 선택하기 전까지 비활성이다.

### 화면 4 — 알림 권한

사용자가 요약 시간을 저장한 뒤 시스템 권한을 요청한다. 거부하면 설정 방법만 안내하고 온보딩을 계속한다.

### 화면 5 — 브리핑 키워드

- 최대 5개
- 직접 입력과 제안 키워드 선택
- 건너뛰기

뉴스 기능을 사용하지 않으면 동의도 요청하지 않는다.

## 3. 오늘 화면

### 3.1 일정 없음

```text
7월 30일 · 오늘의 분위기

오늘은 어떤 하루를 보내고 싶으신가요?
한 문장으로 알려주셔도 좋아요.

[Agent에게 요청] [직접 추가]

오늘의 브리핑
```

표시 조건:

```text
오늘 생성된 일정 수 == 0
```

완료한 일정이 있었던 날에는 빈 상태로 돌아가지 않는다.

### 3.2 일정 있음

```text
오늘의 의도

오전
일정 카드

오후
일정 카드

저녁
일정 카드

언제든
일정 카드
```

### 일정 카드 표시 필드

| 필드 | 조건 |
|---|---|
| 완료 컨트롤 | 할 일일 때 |
| emoji | 값이 있을 때 |
| title | 항상 |
| startAt–endAt | 시간이 있을 때 |
| timeBucket | 시간이 없을 때 |
| estimatedMinutes | 값이 있을 때 |
| recurring icon | 반복 일정일 때 |
| progress | 일부 완료일 때 |
| color | 카드 강조색 |

카드 메뉴:

- 수정
- 오늘 건너뛰기
- 내일로 이동
- 반복 설정
- 삭제

## 4. 일정 생성·편집

### 필수

- 제목
- 날짜
- 유형: 시간 일정 또는 할 일

### 선택

- 이모지
- 메모
- 하루 시간대
- 시작·종료 시간
- 마감일(할 일만, 선택)
- 예상 소요 시간
- 반복
- 시작 전 알림
- 색상

날짜와 시간은 시스템 `DatePicker`를 사용한다. 시간 일정과 할 일 모두 시작·종료 기간을 가질 수 있고, 할 일은 선택적으로 `dueAt`을 가진다. `dueAt`은 별도 일정 종류가 아니다.

노트의 Agent 메뉴는 문장 정리·할 일 분해·준비물 제안을 제공한다. 변경 결과는 저장 전에 편집 필드에서 확인할 수 있어야 한다.

시간을 입력하면 하루 시간대는 자동 계산하되 사용자가 바꿀 수 있다.

## 5. 하루 요약

### 진입

- 설정 시간 알림 탭
- 오늘 화면의 “하루 정리하기”
- 당일 이후 수동 실행

### 화면 1 — 시작

```text
오늘 하루를 정리해 볼까요?

완료하지 않은 일정 3개가 있어요.
[시작] [나중에]
```

### 화면 2 — 일정별 확인

```text
✍️ 문서 정리는 어떻게 되었나요?

[완료했어요]
[일부만 했어요]
[오늘은 건너뛰었어요]
[내일로 옮길게요]
[다른 시간으로 변경]
```

표시 필드:

- title
- emoji
- 예정 시간 또는 timeBucket
- note 일부
- 원래 계획 날짜
- 반복 여부

### 일부 완료

- 25%·50%·75%
- 직접 입력은 1~99%
- 남은 작업 생성은 결과 확인 후 별도 “남은 일 만들기”로 실행

### 내일로 이동

- 원본 일정은 `rescheduled`
- 내일 날짜에 새 일정 생성
- 반복 일정의 규칙 자체는 변경하지 않음

### 화면 3 — 결과

```text
오늘의 기록

완료 3
일부 완료 1
내일로 이동 1

오늘을 한 문장으로 남겨볼까요?
[선택 입력]
```

생산성 점수나 부정적 평가 문구는 사용하지 않는다.

## 6. 잠금화면 위젯

### 일정 없음

```text
오늘은 어떤 하루를 보내고 싶으신가요?
```

탭 목적지:

```text
/plan/new
```

### 일정 있음

- 다음 일정
- 남은 일정 수
- 오늘의 의도

### 요약 시간 이후 미완료 일정 있음

```text
오늘을 정리할 시간이예요 · 2개 확인
```

탭 목적지:

```text
/review/today
```

### 개인정보 숨김

제목 대신 다음 일정 시간과 개수만 표시한다.

## 7. 설정 화면

### 외형

- 기본 면은 시스템 semantic 흑백을 사용한다.
- 브랜드 보라는 로고, eyebrow, 할 일 구분, Agent 근거에만 사용한다.
- MVP는 iOS 시스템 Light/Dark 설정을 따른다.
- 자유 HEX, 화면별 테마, 앱 전용 Light/Dark 강제 토글은 제공하지 않는다.

### 하루 요약

- 활성화
- 시간
- 요일
- 한 줄 회고

질문 대상은 항상 미완료 Todo다. 완료 Todo는 결과 화면 통계에만 표시한다.

### 알림

- 일정 알림
- 하루 요약
- 뉴스 브리핑
- 소리
- 조용한 시간
- 시스템 권한 상태

### 뉴스 브리핑

- 활성화
- 받을 현지 시각
- 요일
- 마지막 생성 시각

자동 브리핑은 사용자 타임존 기준 하루 최대 한 번 생성한다. 조용한 시간과 겹치면 다음 허용 시각으로 미루며, 이미 그 현지 날짜의 브리핑이 있으면 다시 생성하지 않는다.

### AI와 개인정보

- 일정 시간만 허용
- 일정 제목 허용
- 일정 메모 허용
- 완료 기록 분석 허용
- 뉴스 관심사 사용 허용
- AI 실행 기록 보기
- AI 기록 삭제
- 모든 AI 기능 끄기
