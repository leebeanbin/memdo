이 문서는 법률 자문을 대체하지 않는 제품·개발 초안이다. 출시 전 대상 국가 기준의 법률 검토와 App Store 개인정보 표시 검토가 필요하다.

출시 기준:

```text
첫 출시 국가: 대한민국
대상 연령: 만 14세 이상
만 14세 미만을 의도적으로 대상으로 하지 않음
공개 출시: 외부 개인정보 전문 검토 승인 필수
```

## 1. 원칙

- 기본 일정 기능은 AI 동의 없이 사용할 수 있다.
- 알림, 캘린더, AI, 뉴스는 각각 별도 동의를 받는다.
- 기능을 사용하려는 순간에 동의를 요청한다.
- 거절해도 앱 핵심 기능을 막지 않는다.
- 완료 여부를 AI나 행동 데이터로 추측하지 않는다.
- 사용자가 승인하기 전 AI 초안은 실제 일정이 아니다.
- 사용자는 동의 철회, 연결 해제, AI 기록 삭제를 할 수 있다.

## 3. AI 데이터 범위

### 최소 범위

- 현재 사용자 메시지
- 사용자가 선택한 날짜
- 사용자가 선택한 분위기

### 선택 범위

- 바쁜 시간
- 일정 제목
- 일정 메모
- 완료 기록
- 관심사

AI 요청에는 선택된 범위 밖의 데이터를 포함하지 않는다.

## 4. AI 행동 등급

### 등급 0 — AI 꺼짐

일정 CRUD, 반복, 알림, 하루 요약은 규칙 기반으로 동작한다.

### 등급 1 — 제안만

AI가 초안을 만들며 모든 저장은 사용자 승인이 필요하다.

### 등급 2 — 승인된 규칙 실행

사용자가 승인한 반복 규칙만 자동으로 일정 인스턴스를 만든다. AI가 매번 다시 판단하지 않는다.

MVP에서는 등급 0~2만 제공한다.

## 5. 동의 화면 필수 요소

- 기능 이름
- 사용하는 데이터
- 사용 목적
- 외부 전송 여부
- 저장 기간
- 거절 시 영향
- 설정에서 철회하는 방법
- 정책 버전

## 6. 철회 처리

### AI 동의 철회

- 신규 AI 호출 차단
- 예약된 AI 브리핑 중지
- 기존 일정 유지
- AI 초안 삭제
- 실행 기록 삭제 옵션 제공

### 캘린더 연결 철회

- OAuth 또는 시스템 접근 해제
- 서버 토큰 폐기
- 외부 일정 신규 동기화 중단
- 이미 가져온 일정 삭제 여부를 사용자에게 선택

### 알림 철회

- 앱 내 알림 설정 비활성화
- 예약된 로컬 알림 취소
- APNs 발송 대상 제외

## 7. 보존 정책 초안

| 데이터 | 기본 보존 |
|---|---|
| 활성 일정 | 계정 유지 기간 |
| 삭제 일정 | 30일 후 영구 삭제 |
| AI 계획 초안 | 24시간 |
| AI 실행 메타데이터 | 30일 |
| 원문 AI 프롬프트 | 기본 미저장 |
| 뉴스 브리핑 | 30일 |
| 동의 이력 | 법적 의무에 필요한 기간 |
| 외부 토큰 | 연결 해제 즉시 폐기 |

## 8. 감사 로그

AI 변경 작업에는 다음을 기록한다.

```text
run_id
user_id
tool_name
대상 리소스 ID
제안 또는 실행 여부
사용자 승인 여부
실행 시각
결과
```

일정 제목·메모 원문은 감사 로그에 중복 저장하지 않는다.

## 9. 사용자용 개인정보 안내 초안

> Memdo는 계획과 일정을 제공하기 위해 사용자가 입력한 정보를 저장합니다. AI 기능은 선택 사항이며, 사용자가 허용한 범위의 정보만 계획 제안 또는 뉴스 요약에 사용합니다. AI는 사용자의 승인 없이 일정을 삭제하거나 완료 처리하지 않습니다. 권한과 AI 기록은 언제든 설정에서 확인하고 삭제할 수 있습니다.

## 10. 출시 전 필수 서류

- 개인정보 처리방침
- 서비스 이용약관
- App Store Privacy Nutrition Labels 답변표
- `PrivacyInfo.xcprivacy`
- 제3자 처리업체 목록
- 데이터 삭제 요청 절차
- 침해사고 대응 절차
- 아동 사용 대상 여부 결정
- 지원 이메일 및 개인정보 문의 채널

책임자는 Founder다. 외부 TestFlight 30일 전 초안을 만들고 공개 출시 30일 전 전문 검토 승인을 받아야 한다. 승인일·검토자·정책 버전을 release record에 남기지 않으면 Store 제출을 차단한다.
